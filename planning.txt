

Ok, so I want to think of 2-3 designs before starting to implement.

It actually probably won't be desinct designs but more messy combination of different possible designs for different classes or
groups of classes.

Features I'm going to start with:
- Typing where caret is
- Clicking on the text changes the caret position
- Backspace and delete (deleting one character)
- selection
    - The mouse dragging over text selects it
    - The mouse clicking removes the selection
    - Typing when text is selected deletes the text
    - Backspace and delete delete the text
- line numbers
- vertical scrolling
- either horizontal scrolling or line wrapping
- reading from and writing to a file

Designs 1:
I want to build a gap buffer data structure in a class because it's the simplest data structure to use besides an array.
It will be a generic one containing no specifics of the project.

https://www.geeksforgeeks.org/dsa/gap-buffer-data-structure/

I got some help from the Design Philosophy book. It used the example of a text editor throughout the book.
One suggestion it had was making the caret and selection box two different classes. I'll do that.

I think it also suggested having a general class for manipulating the text not containing any specifics of the text editor. Like
it's a class that can be used to manipulate text in a wide variety of programs.
The class contains a delete method, which takes in a start and end position and deletes everything inbetween. If the end position
is equal to or less than the start position, it does not throw an exception, it just does nothing.
The insert method takes a position and the character to input.
