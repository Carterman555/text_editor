

Ok, so I want to think of 2-3 designs before starting to implement.

Features I'm going to start with:
- Typing where caret is
- Clicking on the text changes the caret position
- Backspace and delete (deleting one character)
- selection
    - The mouse dragging over text selects it
    - The mouse clicking removes the selection
    - Typing when text is selected deletes the text
    - Backspace and delete delete the text
- line numbers
- vertical scrolling
- either horizontal scrolling or line wrapping
- reading from and writing to a file
